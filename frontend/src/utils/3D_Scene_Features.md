# 增强版3D场景功能说明

## 新增功能

### 1. 模型导入功能
- **支持格式**: GLTF/GLB, OBJ, FBX
- **操作方式**: 点击工具栏"导入模型"按钮，选择文件
- **自动特性**: 
  - 自动设置阴影
  - 自动注册为设备
  - 支持动画播放

### 2. 内置建模工具
- **工业泵**: 包含泵体、电机、管道、压力表等
- **储罐**: 包含罐体、支架、液位指示器、人孔等
- **换热器**: 包含壳体、管束、进出口等
- **阀门**: 支持闸阀和球阀两种类型
- **传送带**: 可自定义长度的传送系统
- **工厂场景**: 预建的完整工厂布局

### 3. 设备数据系统
- **实时显示**: 设备上方悬浮数据标签
- **数据面板**: 右侧统一显示所有设备数据
- **状态指示**: 
  - 正常（绿色）
  - 警告（橙色）
  - 危险（红色）
- **视觉反馈**: 
  - 根据温度/压力等参数改变颜色
  - 转速控制旋转动画
  - 液位显示（储罐）
  - 报警闪烁效果

### 4. 数据模拟
- **自动生成**: 根据设备类型生成合理的模拟数据
- **实时更新**: 每2秒更新一次数据
- **支持参数**:
  - 温度、压力、流量
  - 转速、功率、扭矩
  - 液位、位置、状态等

## 操作指南

### 基本操作
1. **导入模型**: 工具栏 → 导入模型 → 选择文件
2. **添加内置模型**: 工具栏 → 内置模型 → 选择类型
3. **显示数据标签**: 工具栏 → 显示标签开关
4. **启动数据模拟**: 工具栏 → 数据模拟开关

### 高级功能
1. **设备配置**: 在右侧面板可以配置设备参数阈值
2. **连接管理**: 设备间可以创建连接关系
3. **场景保存**: 支持保存和加载完整场景
4. **视图控制**: 重置视图、适应屏幕、线框模式等

## 技术特性

### 渲染特性
- **PBR材质**: 物理基础渲染，支持金属度、粗糙度
- **实时阴影**: PCF软阴影，提升视觉质量
- **抗锯齿**: 多重采样抗锯齿
- **透明支持**: 玻璃、液体等透明材质

### 性能优化
- **几何体合并**: 减少绘制调用
- **材质共享**: 优化内存使用
- **LOD支持**: 距离相关的细节层次
- **视锥剔除**: 只渲染可见对象

### 扩展性
- **模块化设计**: 各功能模块独立
- **配置驱动**: 设备参数通过配置定义
- **插件架构**: 易于添加新的设备类型
- **API接口**: 支持外部数据集成

## 设备类型配置

### 泵设备
```javascript
{
  units: {
    pressure: ' bar',
    flow: ' L/min', 
    temperature: ' °C',
    power: ' W'
  },
  thresholds: {
    temperature: { warning: 60, danger: 80 },
    pressure: { warning: 8, danger: 10 }
  },
  colorMapping: {
    parameter: 'temperature',
    range: { min: 20, max: 100 }
  }
}
```

### 储罐设备
```javascript
{
  units: {
    level: ' %',
    temperature: ' °C',
    pressure: ' bar'
  },
  levelDisplay: {
    parameter: 'level',
    range: { min: 0, max: 100 }
  }
}
```

## 故障排除

### 常见问题
1. **模型导入失败**: 检查文件格式是否支持
2. **数据不更新**: 确保启用了数据模拟
3. **标签不显示**: 检查显示标签开关状态
4. **性能问题**: 减少场景中的对象数量

### 浏览器兼容性
- **推荐**: Chrome 90+, Firefox 88+, Safari 14+
- **要求**: 支持WebGL 2.0
- **内存**: 建议4GB以上可用内存
